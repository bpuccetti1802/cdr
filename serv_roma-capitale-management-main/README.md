# Roma-capitale-management
## Descrizione
Progetto di BE che fornisce le funzionalità di configurazione dei
microservizi e la profilazione utente.

## Dipendenze
Moduli necessari per la compilazione e l'avvio del progetto sono:<br>
- **Roma-capitale-management-integration**: Libreria contenente le classi necessarie per le chiamate interne, collocato in roma-capitale-common-jar.<br>
- **Roma-capitale-common-jar**: Libreria base del framework<br>


## Database
Il database utilizzato è il nuovo database postgres.
La guida per la creazione si trova in documentation.
